設問28


次のプログラムをコンパイル、実行したときの結果として、正しいものを選べ（１つ）


```
Path p = Paths.get("a/b/c/../../d");
System.out.println(p.normalize());

```

A. 「a/d」と表示される

B. 「a/b/c/././d」と表示される

C. 「a/b/c/../../d」と表示される

D. 「a/b/c/d」と表示される




#normalize() 
パス中の「.」「..」を正規化して、可能な限り簡略化  

今回のパス：  
`a/b/c/../../d`  
を正規化すると 「a/d」 になる。  


■処理の流れ

`a/b/c/../../d`  

〇normalize のルール  

```
. → 無視
.. → 1 つ前のディレクトリを消す
```

**ただし「ルートを越えない範囲」で消す**  


□ステップごとの変化  
a/b/c/../../d  

c を .. で消す → a/b/../d  

b を .. で消す → a/d  

結果：
a/d
