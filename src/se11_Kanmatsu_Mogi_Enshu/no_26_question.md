設問26


インタフェースと抽象クラスの違いに関する説明として、正しいものを選べ（2つ）


A. インタフェースにはインスタンスフィールドを定義できないが、抽象クラスにはできる


B. インタフェースにはstaticメソッドを定義できないが、抽象クラスには定義できる


C. インタフェースにはprotectedなメソッドを定義できないが、抽象クラスにはできる


D. finalメソッドは、インタフェースにも抽象クラスにも定義できる


E. 実装があるメソッドは、インタフェースに定義できないが、抽象クラスには定義できる




#整理事項は下記の通り  

■(1) インスタンスフィールドについて  
**インタフェースに書けるフィールドは public static final（定数）だけです。**  
**抽象クラスは普通のクラスなので インスタンスフィールドを持てる。**   


■(2)staticメソッドの定義
**Java 8 以降、インタフェースにも static メソッドは定義できる。**  
※抽象クラスには従来から定義できる  


■(3)実装があるメソッド
Java 8 以降、インタフェースには default メソッド（実装付き） を定義できる。
※抽象クラスには従来から定義できる  


■(4)protectedメソッド

**インタフェースにはprotectedなメソッドを定義できないが、抽象クラスにはできる**  

インタフェースのメソッドは

public
private（Java 9〜）
のみ。
※protected は不可。
**インタフェースは “公開契約（public API）” を定義するための仕組みであり、protected のような “限定公開” は契約の概念と矛盾するため禁止されている。**  

抽象クラスは通常のクラスなので protected メソッド OK。  


■(4)finalメソッド

インタフェースのメソッドは
default
static
private
のみで、final は不可。

抽象クラスには final メソッドを定義できるが、インタフェースにはできない。
**インタフェースは “実装クラスがオーバーライドすることを前提とした契約” であり、final は “オーバーライド禁止” を意味するため、インタフェースに置くことは論理的に不可能。**
