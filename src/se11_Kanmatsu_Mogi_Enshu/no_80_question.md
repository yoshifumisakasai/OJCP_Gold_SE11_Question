次のようなセキュリティポリシーファイルで適用されているライブラリがある。このセキュリティポリシーに関する説明として、正しいものを選べ（１つ）


```

grant codebase "sample/lib.jar" {

 permission java.security.AllPermission;
};

```


A. 過剰な権限が与えられているので、付与を削除する


B. 必要な権限のみをリストにすることは問題ないので、何もしない


C. 内部ツールであり、外部に公開されないので、何もしない


D. 過剰な権限付与を参照するツールに対するセキュリティリスクを、責任者に正式に報告する


E. 調査しているバグとは関係ないので、何もしない





#セキュリティポリシーファイル
Java のセキュリティポリシーファイル（policy ファイル）で、特定の JAR に権限を与える設定

〇 “codebase” は「どの JAR に対して権限を与えるか」を指定する  



#✔ AllPermission とは？
すべての権限を許可する最強の権限

ファイル読み書き、ネットワークアクセス、クラスローダ操作、反射、暗号、すべて許可

**実質的に SecurityManager を無効化するのと同じ**  

つまり：

外部ライブラリに AllPermission を与えるのは重大なセキュリティリスク。
