設問42

次のうち、オートボクシングが成功するコードを選べ（2つ）


A. Float a = 1.0;


B. Long b = 10L;


C. Integer c = 10;


D. Double d = 10;




#ポイント
**オートボクシングは プリミティブ → 対応するラッパークラス の変換**  


-----------------------------------------------


D. Double d = 10;
❌ 失敗（コンパイルエラー）

理由：
10 は int リテラル。
オートボクシングは int → Integer であって、int → Double は 型変換できない。
**Java は「暗黙の数値型変換 → ボクシング」という複合変換をしない。**




A. Float a = 1.0;
❌ 失敗（コンパイルエラー）

理由：
1.0 は double リテラル。
オートボクシングは プリミティブ → 対応するラッパークラス の変換だけ。

つまり：

double → Double（OK）
double → Float（NG）

よって Float に double を代入することはできない。


-----------------------------------

#Java の数値リテラル仕様

■なぜ 1.0 は double なのか（Java の数値リテラル仕様）
**Java の数値リテラルは サフィックスが付いていない場合、浮動小数点は必ず double として扱われる。**  

＜浮動小数点リテラルの規則（Java Language Specification）＞  
1.0 → double

1.0d → double

1.0D → double

1.0f → float

1.0F → float

*サフィックスが f / F を付けない限り、Java は 浮動小数点リテラルを double として扱う。*
