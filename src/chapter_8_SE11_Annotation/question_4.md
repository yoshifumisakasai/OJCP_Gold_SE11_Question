設問4


独自のアノテーションを定義するとき、@Targetアノテーションを指定しなかった。このとき、アノテーションの対象となるものを選べ（１つ）

A. クラス

B. メソッド

C. フィールド

D. コンストラクタ

E. 上記のすべて


#@Target を 指定しなかった場合、
アノテーションは すべての要素に適用可能  
**クラス・メソッド・フィールド・コンストラクタなど、Java が定義しているすべての ElementType が対象になる**  


#@Target を指定しない場合の仕様  
Java の @Target は「このアノテーションをどこに付けられるか」を制限するためのものですが、指定しない場合は制限なし（＝全ての場所に付けられる） というデフォルト動作になります  


■ @Target の例（試験対策）  

```
@Target(ElementType.METHOD)
public @interface Sample {}
```

⇒メソッドにしか付けられない
